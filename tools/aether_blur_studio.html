AetherBlur Compose Engine Architecture

class AetherBlurEngine : ComposeRenderEffectContract {

@RequiresApi(Build.VERSION_CODES.S)

fun createRenderEffect(radius: Float, saturation: Float): RenderEffect {

val blur = RenderEffect.createBlurEffect(radius, radius, Shader.TileMode.CLAMP)

val colorMatrix = ColorMatrix().apply { setToSaturation(saturation) }

val colorFilter = RenderEffect.createColorFilterEffect(ColorMatrixColorFilter(colorMatrix))

return RenderEffect.createChainEffect(colorFilter, blur)

}

}

OLED Anti-Banding & Dither Mechanics

On mobile OLED displays with 8-bit color channels, strong Gaussian blurs on dark gradients frequently exhibit unsightly stepped rings known as color banding. AetherBlur integrates a high-frequency micro-grain procedural texture overlay (3.5% opacity) to distribute quantization noise evenly, simulating analog frosted silica glass.
